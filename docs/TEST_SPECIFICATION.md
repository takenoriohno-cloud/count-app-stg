## 1. テスト概要

### 1.1 目的
要件定義書（v1.1.0）に記載されたUI/UX要件、音響・視覚効果、データ永続化、CSV出力、2段階リセットに加え、**Googleスプレッドシート連携、合言葉パスワード認証によるBOT排除、15分定期自動送信、およびUNDO取り消し整合性**が正常に動作することを体系的に検証する。

### 1.2 テスト対象環境
- **主対象（クライアント）**: iPhone Safari (iOS 15 / 16 / 17 / 18)
- **ステージング環境**: [https://takenoriohno-cloud.github.io/count-app-stg/](https://takenoriohno-cloud.github.io/count-app-stg/)
- **バックエンド API**: Google Apps Script (GAS) Web Apps
- **自動テストハーネス**: PowerShell / E2E Integration Suite (`tests/test_e2e.ps1`)

## 2. テストケース一覧

### 2.1 UI / レイアウト検証

| ID | テスト項目 | 確認手順 | 期待される結果 |

| **TC-UI-01** | 初期表示とSafe Area | iPhone Safariでページを開く | 上部ヘッダーや最下部ボタンがノッチやホームバーと重ならず適正に余白が確保されていること |

| ID | テスト項目 | 確認手順 | 期待される結果 |

### 2.3 音響 & アニメーション検証

| ID | テスト項目 | 確認手順 | 期待される結果 |
| :--- | :--- | :--- | :--- |
| **TC-AUD-01** | 初回タップ時の音声再生 | ページ読み込み後、最初のボタンをタップ | iOSのAudioContextサスペンドが解除され、遅延なくクリック音（800Hz）が鳴ること |

| **TC-ANI-02** | 発光フィードバック | ボタンを離す | ボタンに瞬間的なグリーンフラッシュアニメーションが付与されること |

### 2.4 取り消し（アンドゥ）機能検証

| ID | テスト項目 | 確認手順 | 期待される結果 |
| :--- | :--- | :--- | :--- |
| **TC-UND-01** | 初期状態のボタン非活性 | カウント0件の状態でアンドゥボタンを確認 | アンドゥボタンが無効化（disabled・半透明）されタップできないこと |
| **TC-UND-02** | 直前入力情報のプレビュー表示 | 「女性 30代」をタップ | アンドゥボタン内に「直前: 女性 / 30代 (HH:MM:SS)」と時刻付きで表示されること |
| **TC-UND-03** | アンドゥ実行による減算 | アンドゥボタンをタップ | ・総配布枚数が1減ること<br>・該当カテゴリーのバッジ・集計表が1減ること<br>・取り消し専用のトースト通知と確認音（低音）が鳴ること |
| **TC-UND-04** | 複数回アンドゥ | 3回カウント後、アンドゥを3回実行 | 過去の履歴が順に遡って取り消され、0件になった時点でボタンが非活性化すること |

### 2.7 Googleスプレッドシート連携 & UNDO整合性 (E2E)

| ID | テスト項目 | 確認手順 | 期待される結果 |
| :--- | :--- | :--- | :--- |
| **TC-E2E-01** | 正常データ送信 (GAS連携) | カウント後に「送信」をタップ | GAS宛てにPOST送信され、スプレッドシート（`raw_logs`）に行が追記されること |
| **TC-E2E-02** | パスワード認証 (BOT排除) | 不正なパスワードで送信を試みる | GAS側で認証エラー（401）となり、スプレッドシートへの書き込みが遮断されること |
| **TC-E2E-03** | 送信済みカウントのUNDO | 送信完了後に「UNDO」をタップして再度送信 | スプレッドシート側の該当レコードのステータス列が「取消」に自動更新されること |
| **TC-E2E-04** | 未送信カウントのUNDO | 送信前のカウントを「UNDO」する | 端末内配列からのみ削除され、スプレッドシートには一切送信されないこと |
